# Privacy and GDPR

## Policy goals

- Minimize personal data collected for digest generation.
- Use pseudonymization or redaction wherever possible.
- Keep retention periods explicit and configurable.
- Provide a clear deletion path for stored email metadata.

## GDPR considerations

- Data processing should be documented and limited to legitimate business purpose.
- Users should be able to review what metadata is retained.
- Model providers must be assessed for international transfer and data handling policies.
- Security logs should avoid storing full raw email content unless required.

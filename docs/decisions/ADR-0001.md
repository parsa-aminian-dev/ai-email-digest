# ADR-0001: Use deterministic rule engine before LLM summarization

Date: 2026-10-06

## Status

Accepted

## Context

The system needs to classify and prioritize email while preserving privacy and predictability. A purely generative approach could misclassify or leak sensitive content.

## Decision

Use a deterministic rule engine to assign category, priority, and routing before any LLM summarization step.

## Consequences

- Improves explainability and auditability
- Reduces model cost and risk
- Keeps LLM usage focused on summarization, not classification
